# 🚀 QuickHandy - Full-Stack Service Booking Platform

QuickHandy is a modern, enterprise-ready Progressive Web Application (PWA) designed to connect clients with professional service providers seamlessly.

## 🌟 Key Features
- **Role-Based Access:** Dedicated, secure interfaces for Clients, Providers, and Admins.
- **Enterprise Admin Dashboard:** Real-time analytics, user management, financial overviews, and dispute handling.
- **Progressive Web App (PWA):** Fully installable on mobile devices providing a native-like experience.
- **Cloud Database:** Highly scalable and secure PostgreSQL database.

## 💻 Tech Stack
- **Frontend:** Next.js, React, Tailwind CSS
- **Backend:** Next.js API Routes, Node.js
- **Database & ORM:** PostgreSQL (Neon), Prisma ORM
- **Deployment & Hosting:** Vercel
